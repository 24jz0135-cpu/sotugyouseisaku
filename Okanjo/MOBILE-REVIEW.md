# スマホで解析結果を確認する

1. PCからDiscordへ返ったOISO解析結果CSVをスマホに保存します。
2. スマホ版の「結果確認」タブで「解析CSVを読み込む」を押し、保存したファイルを選びます。
3. 店舗名・日付・金額（整数円）・科目を確認／修正します。修正は入力ごとにこのブラウザーへ保存され、修正した明細は未確認へ戻ります。
4. 各明細の「内容を確認済みにする」を押します。未入力項目や不正な日付・金額がある明細は確定できません。
5. 「確認済み○件をCSV保存」で確認済みだけ出力します。「作業中の全件をCSV保存」には未確認も含まれます。

同じレシートIDを再度取り込んでも保存済みの修正を上書きせず、追加しなかった件数を表示します。訂正は既存の明細から行ってください。1ファイル2MB、保存5000件まで、表示は20件ずつです。OISOのUTF-8 CSV（receiptId,date,vendor,amount,category、任意のconfidence列）に対応します。

読み込みは一括検証し、CSVにID重複や不正な列構成がある場合は既存データを変更しません。ストレージに保存できなかった修正は反映せず、画面にエラーを表示します。保存データが破損している場合は上書きを停止します。

この確認一覧はホームの既存会計データ・`.oaiso`端末バックアップとは独立です。端末の保存領域を消す前に全件CSVを保存してください。CSVには確認済みフラグを含めず、新規取り込み時は再確認のため全件未確認にします。CSVは直接e-Taxへ取り込む形式ではありません。

現在はDiscordの添付を手動で読み込む方式です。自動受信・PCやDiscordへの自動返送・元のレシート画像との照合は未実装です。元画像と照合する場合はDiscordなどで画像を開いてください。公開サイトへのデプロイは別途必要です。
