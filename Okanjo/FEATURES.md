# OISO 実装済み機能一覧

2026年11月10日時点。スマホでレシートを保管し、PCで解析・確認・経費集計する構成です。
「実装済み」と「実機・外部サービスを含む動作確認済み」は区別しています。

## スマホ版（Flutter Android）

- ダッシュボード: 月の合計、未確定・確定済みの件数と金額、カテゴリ別内訳。
- 会計記録: 追加、編集、確定、履歴の絞り込み。
- レシート保管: カメラ撮影、ギャラリーから選択、端末内保存、一覧、拡大、削除。
- PC連携: QRコードを読み取って送信先を設定し、Relayで画像を送信。
- 解析結果確認: PCのCSVを手動で取り込み、編集・確定・共有。
- 見た目: 5色テーマ、背景やカードへの写真設定、範囲選択、薄く表示、写真解除、プリセット保存・適用。
- バックアップ: `.oaiso` の保存・復元。会計記録、解析結果、レシート画像、テーマ写真、設定、プリセットを保存。
- 別端末への復元: 画像参照先を復元先へ置き換え。不正な画像データやレビュー配列を会計データの書き換え前に検出。

## スマホWeb版

- 会計・レシート保管の画面、テーマ写真・範囲選択・プリセット、使い方ガイド。
- QRによるRelay送信。画像を1枚ずつ送信し、送信済み記録を保持。
- 途中失敗からの再開、混雑時の再試行、送信ボタンの連打防止。
- 解析CSVの取り込み、編集、確認済み管理、保存。重複取り込み時は既存の編集を保護。
- 解析結果確認一覧は既存の会計記録・端末バックアップとは別管理。

## PC版（OISO2）

- レシート画像の一括追加、分析用画像とmanifest作成、Bridge受信箱からの取り込み。
- PCからBridgeへの画像直接保存。JPEG・PNG・WebP・GIF、1枚20MB以内。
- Codex CLIを使ったAI解析で店名・日付・金額・科目候補を抽出。初期設定のmockでは空欄を作成。
- 解析結果のCSV・JSON取り込み、内容の修正、CSV出力。再取り込み時に編集済み明細を保護。
- 画像一覧・編集内容・集計設定を同じブラウザーURLで復元。JSONバックアップで明細を移行。
- 年・計上日・科目・事業割合・按分メモ・確認状態を指定して経費を集計。
- 返品・返金の負数、私用分・対象年外・対象外明細の除外、要確認明細の検出。
- 申告入力補助用の集計CSVと明細CSVを出力。e-Taxへの直接送信や申告書全体の作成には未対応。

## Bridge・共通部分

- ローカルAPIとPC画面の配信、受信画像・解析結果の保存。
- Discord・common-relayを介したスマホからPCへの配送、ペアリングと一時QR、解析結果の返送処理。
- 期限切れセッションの整理、途中受信ファイルの保護、保存済み画像の受信確認。
- 共通バックエンドにAPI・アップロード・検証・集計用コードとD1マイグレーションを配置。公開運用の確認とは別扱い。
