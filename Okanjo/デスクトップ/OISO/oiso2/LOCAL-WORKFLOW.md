# PC版のローカル作業

`start.ps1` でBridgeを起動し、http://127.0.0.1:8788/ を開きます。画面もBridgeから配信されるため、別のWebサーバーは不要です。既存の4174番のプレビューも利用できます。

1. JPEG / PNG / WebP / GIF画像を追加します。Bridgeへ保存する画像は1枚20MB以内です。
2. 「追加した画像を解析」を押します。初期設定のmockでは読み取りを行わず、入力用の空欄を作成します。
3. 店舗名・日付・金額・勘定科目を入力・修正し、「確認・修正したCSVを保存」を押します。
4. 必要に応じて経費科目・事業割合・計上日を設定し、確認済みにすると経費集計CSVを出力できます。

実AI読み取りにはCodex CLIの設定とログインが別途必要です。今回の確認はmockモードです。

画像一覧はIndexedDB、明細・編集内容・経費集計設定はlocalStorageへ保存します。同じURLのブラウザーで再読み込みすると復元します。4174と8788は保存領域が異なるので、普段使うURLを固定してください。明細はJSONバックアップから別URLへ移せます。ブラウザーのデータ消去で保存内容も消えるため、元画像とJSONバックアップを保管してください。

再取り込み時は同じIDの編集済み明細を既定で保護します。解析結果で置き換える場合は、CSV/JSON取り込みの「取り込んだ内容で更新」を選びます。保存失敗は画面に表示されます。画像の削除は画面一覧からの削除で、Bridge受信箱の元画像は削除しません。

確認: desktop.test.mjs、desktop-storage.test.mjs、tax.test.mjs、relay.test.mjs。
