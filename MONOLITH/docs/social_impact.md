# MONOLITH の社会的意義

## 1. 背景：個人事業主の「証拠」問題

日本には約 500 万人の個人事業主・フリーランスが存在する（総務省統計局）。
彼らの多くは、取引の証拠（レシート、納品書、位置情報など）を十分に保存できず、以下のリスクに晒されている：

- **税務調査**での追加課税リスク
- **クライアントとのトラブル**での請求破棄リスク
- **融資審査**での信用履歴不足

特に小規模事業者は、会計ソフトの操作が煩雑で、取引のたびに証拠を意識的に保存する習慣が根付いていない。

## 2. MONOLITH が解決すること

### 2.1 「記録＝証拠」の自動化
MONOLITH は、記録の瞬間に自動で位置情報・端末情報を付与する。
これにより、ユーザーは意識的に「証拠を残す」ことなく、自然な記録行為の中で法的証拠力を持つデータが生成される。

### 2.2 デジタル・デバイドの縮小
高価な会計ソフトや専門知識が不要。スマートフォン一台で、誰でも取引の証跡管理が可能になる。
これにより、小規模事業者・高齢起業者・障害者起業者など、デジタル活用に不安のある層も含めた包容的な金融インフラを目指す。

### 2.3 監査可能性（Auditability）の民主化
大企業にしかなかった「内部統制・監査証跡」を、個人レベルで実現する。
これは、インボイス制度や電子帳簿保存法の普及に伴い、個人事業主に求められている「適正な記帳義務」を技術的に支援する。

## 3. 倫理的配慮

### 3.1 プライバシー
- 位置情報は端末内で暗号化し、ユーザーが明示的に許可した場合のみサーバーに送信
- 「振動検知」は端末ローカルで処理し、生の加速度データは保存しない

### 3.2 透明性
- 収集するデータの種類・目的を明確に開示
- オープンソース化を検討し、アルゴリズムの公平性を検証可能にする

### 3.3 データ主権
- ユーザーのデータはエクスポート可能（CSV / JSON）
- プラットフォームロックインを避け、他の会計ソフトへの移行を容易にする

## 4. 期待される社会的インパクト

| 指標 | 目標値（3年後） |
|---|---|
| 個人事業者の税務調査対応率向上 | +30% |
| 会計処理にかかる月間工数削減 | 平均 5時間 → 2時間 |
| デジタル支援対象事業者の利用率 | 全ユーザーの 20% |

## 5. 結論

MONOLITH は「単なる会計アプリ」ではなく、**個人事業主の経済的自律と法的安全を保障するための社会基盤**を目指す。
テクノロジーを通じて、小さな事業者にも「大企業レベルの監査可能性」を提供し、日本の経済の底辺を支えるインフラとなることを目標とする。
