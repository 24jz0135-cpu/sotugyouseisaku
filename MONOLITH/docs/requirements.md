# MONOLITH 要件定義書

## 1. プロジェクト概要

MONOLITH は、個人事業主・フリーランス向けの「取引の証拠」を自動付与するモバイル会計アプリである。センサー情報（位置・振動）と OCR 画像を取引記録に紐付けることで、税務調査や契約トラブルに備えた「不変の台帳」を形成する。

## 2. 機能要件

### 2.1 取引記録（CRUD）
- 収入・支出の両方を記録可能
- 金額、勘定科目、備考を入力
- ボイスメモによる音声入力（将来的な拡張）

### 2.2 センサー証拠
- **位置情報**: GPS による緯度・経度を自動取得
- **振動検知**: 加速度センサーでレジの振動を検知し、取引発生タイミングを補助証明
- **デバイス ID**: どの端末で記録したかを追跡可能

### 2.3 OCR / 画像解析
- レシート・納品書のカメラ撮影
- 画像のモノクロ・リサイズ前処理
- テキスト抽出（金額、日付、店舗名など）
- 抽出結果をエントリーに自動連携

### 2.4 分析・可視化
- 月次・年次の収支サマリー
- カテゴリ別グラフ（棒グラフ・円グラフ）
- 取引一覧のフィルタリング（収入 / 支出 / すべて）

### 2.5 データ永続化
- Cloudflare D1（SQLite）による構造化データ保存
- Cloudflare R2（オブジェクトストレージ）による画像保存（将来対応）
- ローカルキャッシュによるオフライン対応（将来対応）

## 3. 非機能要件

### 3.1 セキュリティ
- 通信は HTTPS のみ
- 認証は Cloudflare Access または JWT を検討
- 個人情報（位置情報）は暗号化保存

### 3.2 パフォーマンス
- 画面遷移は 300ms 以内
- OCR 処理は 3 秒以内に完了（モック時は即座に返却）
- API レスポンスは 200ms 以内（エッジから）

### 3.3 可用性
- Cloudflare Workers のグローバルエッジにより 99.9% 以上の可用性
- D1 は自動バックアップ対応

### 3.4 デザイン
- **モノクロ UI**（白黒のみ）
- 高コントラストで視認性を確保
- フォントは等幅またはサンセリフの太字を使用

## 4. 技術スタック

| 層 | 技術 |
|---|---|
| フロントエンド | React Native (Expo) |
| バックエンド | Cloudflare Workers + Hono |
| データベース | Cloudflare D1 (SQLite) |
| 画像ストレージ | Cloudflare R2（将来） |
| OCR | Google Vision API / Tesseract.js / Cloudflare AI（将来検討） |

- AI による自動仕訳提案
- 複数ユーザー・組織対応
